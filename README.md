# АвтоКит — сайт с формой заявки на подбор запчастей

Современный одностраничный сайт на двух языках (русский / қазақша).

## Что есть

- Переключатель языка RU / KZ
- Форма заявки: VIN (номер кузова), марка/модель, список запчастей
- Заявка уходит **напрямую в WhatsApp** — личные данные не собираются
- Адрес, телефон, ссылка на akit.kz
- Адаптивный современный дизайн

## Как открыть

Просто откройте `index.html` в браузере или загрузите папку на любой хостинг (GitHub Pages, Netlify, Vercel, хостинг в KZ и т.д.).

## Kaspi / Halyk Market

Имеет смысл добавить **прямую ссылку на ваш магазин на Kaspi**, если он есть — Kaspi в Казахстане основной канал онлайн-покупок.  
Halyk Market менее популярен, но тоже можно добавить, если магазин там зарегистрирован.

В блоке контактов уже есть кнопки-заглушки — замените `href` на реальные ссылки ваших магазинов.
